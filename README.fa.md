# ZCode اسمارت RTL 🇮🇷 🇸🇦 🇮🇱

[English](README.md) | [فارسی](README.fa.md)

یک پچر و شخصی‌ساز هوشمند **راست‌چین (RTL)** برای برنامه دسکتاپ **ZCode** که پشتیبانی بومی از زبان‌های فارسی، عربی و عبری را همراه با فونت‌های قابل‌سفارشی و ویجت تنظیمات شناور به ارمغان می‌آورد.

> الهام‌گرفته از [antigravity-rtl](https://github.com/AriaRazavi2005/antigravity-rtl).

---

## ✨ امکانات

- **تشخیص خودکار RTL:** متن‌های ورودی و خروجی فارسی/عربی/عبری را در لحظه تشخیص می‌دهد.
- **تشخیص هوشمند جهت در جملات ترکیبی:** حتی وقتی جمله فارسی با کلمه انگلیسی شروع می‌شود (مثل «Docker یک ابزار عالی است»)، به‌درستی راست‌چین می‌شود — با تحلیل نسبت کاراکترها، نه فقط حرف اول.
- **فونت وزیرمتن متغیر (داخلی):** فونت زیبای Vazirmatn به‌صورت آفلاین داخل پکیج قرار دارد.
- **فونت سفارشی:** فونت فارسی دلخواه (مثل شبنم، ایران‌سنس، دانا، وزیرمتن) و فونت انگلیسی خودتان را تنظیم کنید.
- **اندازه فونت و فاصله خطوط واقعاً کار می‌کند:** توکن‌های تایپوگرافی ZCode (`--ui-font-size`، `--text-ui-*`، `--tw-leading`) و کانتینرهای `.prose` / مارک‌داون را مستقیماً بازنویسی می‌کند، پس اسلایدرها روی متن چت واقعاً اثر می‌گذارند.
- **ویجت تنظیمات شناور:** یک ویجت مدرن برای تنظیم:
  - روشن/خاموش کردن RTL (میانبر سریع: `Alt + R`)
  - حالت Force RTL (راست‌چین اجباری حتی وقتی متن با کلمه انگلیسی شروع می‌شود)
  - فونت‌های سفارشی فارسی، انگلیسی و کدنویسی
  - اسلایدر فاصله خطوط چت (با نمایش مقدار لحظه‌ای)
  - اسلایدر اندازه فونت (با نمایش مقدار لحظه‌ای)
  - فیکس `@` کیبورد فارسی (`Shift + 2` به‌جای `٬` علامت `@` تایپ می‌کند)
- **باز کردن DevTools:** راست‌کلیک → *Inspect Element* در نسخه نصب‌شده فعال می‌شود (پچ مقاوم در برابر تغییر نسخه).
- **امن و قابل بازگشت:** قبل از پچ، به‌صورت خودکار یک بکاپ (`app.asar.bak`) می‌گیرد و با یک دستور می‌توانید به حالت اولیه برگردید. اگر `app.asar` بر اثر یک پچ نیمه‌کاره خراب شود، پچر خودش از بکاپ بازیابی می‌کند.
- **اجرای مجدد خودکار:** بعد از پچ، در صورت تمایل ZCode را خودش اجرا می‌کند.
- **چندسکویی:** روی ویندوز، مک و لینوکس کار می‌کند.

## ⚠️ نکته مهم: آپدیت‌های ZCode

آپدیتر خودکار ZCode فایل `app.asar` را جایگزین می‌کند و **پچ (و فایل بکاپ) را پاک می‌کند**. بعد از هر آپدیت ZCode کافی است دوباره پچر را اجرا کنید:

```bash
npx zcode-rtl
```

## 🚀 شروع سریع

### ۱. اجرا با `npx` (بدون نیاز به نصب)

```bash
npx zcode-rtl
```

### ۲. یا نصب سراسری

```bash
npm install -g zcode-rtl
zcode-rtl
```

> **نکته برای کاربران ویندوز:** اگر ZCode در مسیر `C:\Program Files` نصب شده، حتماً ترمینال (CMD یا PowerShell) را با دسترسی **Run as Administrator** اجرا کنید.
>
> **نکته برای کاربران مک / لینوکس:** با `sudo` اجرا کنید:
> ```bash
> sudo npx zcode-rtl
> ```

## ⚙️ تنظیمات و میانبرها

| قابلیت | توضیح | پیش‌فرض |
| :--- | :--- | :--- |
| **روشن/خاموش RTL** | `Alt + R` | روشن |
| **فیکس @ کیبورد فارسی** | با `Shift + 2` علامت `@` تایپ می‌شود | فعال |
| **فونت پیش‌فرض فارسی** | وزیرمتن متغیر (Vazirmatn Variable) | داخل پکیج |
| **محل ذخیره تنظیمات** | `localStorage` مرورگر (کلید: `zcode-rtl-config`) | ذخیره خودکار |
